# 食事姿勢サポートの根拠・適用範囲・評価計画

更新: 2026-11-11

## 結論

このシステムは、**個人が決めた無理のない食事時の着座姿勢からの持続的な逸脱を知らせる**ための研究プロトタイプである。嚥下機能・誤嚥リスクをカメラで判定する機器ではなく、**臨床での効果も未検証**である。

| 検討事項 | 根拠の強さと解釈 | 実装方針 |
| --- | --- | --- |
| 食事時の姿勢・座位 | 摂食嚥下アセスメントで姿勢・環境を考慮することは専門ガイドに含まれる [1][2]。高齢者嚥下障害の白書は直立座位を一般的に勧めている [3] | 利用者の**基準座位**を記録し、継続する大きな逸脱を知らせる |
| 顎引き・頭部回旋 | 効果は患者・障害像により異なり、個別に評価すべき代償技法である [1][2][4] | 「顎を引け」「首を回せ」という**一律の治療指示をしない** |
| 食後30分の座位 | 一般的な勧めはあるが、時間について強い根拠は不足し個別化が必要と明記 [2] | **固定の医療指示や安全保証に使わない**。必要なら専門職が計画する |
| 単眼カメラの角度推定 | 画角・撮影方向で誤差が変わる [5]。遮蔽でランドマーク欠損が生じる | 絶対角度で「安全」を判定しない。個人基準・信頼度・`unknown` を使う |
| 画面表示や音声の頻度 | 本試作の 2.5秒持続、10秒最短通知間隔、35秒再通知は**UX上の暫定設計値**であり、臨床研究由来ではない | 食事動作を妨げないか、実利用者の実験で調整する |

## 実装に反映した安全な境界

1. **食事中に足が見えなくても使用可能にする**: 初期値 `feet.enabled=false`。足を追跡できても足底荷重・床接触は分からないため、足の位置を確認する表現のみを使う。
2. **むやみに口元を直させない**: 頭部の逸脱があっても顎引きの一律な指示は出さず「基準姿勢へ無理なく戻す」と伝える。医療職が指定した代償姿勢がある場合は、その指示を優先し、必要に応じて指標を無効化する。
3. **短時間の前屈を咎めない**: 食物を取る自然な動作は一時的な変化になり得るため、警告確定には一定時間を要し、手動の `P` で一時停止できる。ただし**摂食・嚥下動作の自動検知は未実装**。
4. **見えないときは判断しない**: 追跡が途切れた指標を直ちに `unknown` と表示し、以前の警告を新しい通知として使わない。顔・耳が見えれば腰が隠れても頭部ピッチのみ計測可能。
5. **連続通知しない**: JSON の `overall_status` と、低頻度で1件ずつ出す `feedback_messages` を分ける。
6. **現場で再登録**: 個人基準はカメラ設置、椅子、姿勢指導の変更で更新する。基準そのものが医学的に適切かはソフトが判定できない。

## セットアップの推奨

- 利用者の同意を得て、食事時と同じ椅子・テーブル・撮影距離で固定カメラを使用する。
- 検出器が**鼻・耳・肩・腰**を安定追跡できる構図を優先する。鏡像表示はプレビューにだけ使う。画角依存の誤差を避けるため、カメラ角度を変えて定量比較する [5]。
- 足を研究項目に含める場合、両脚・両足先が映る別構図を用意する。単眼映像だけで足台接触を評価したいなら荷重センサー等の別データが必要。
- 基準姿勢の登録前に、本人と介助者・言語聴覚士等が「無理なく維持できる座位」を確認する。痛み・バランス・既存の指示がある場合は無理に直立させない。
- データの映像保存・外部送信は標準実装に含まれない。基準値はローカル JSON に保存される。研究でログを追加するなら同意、保管期間、匿名化を別途設計する。

## 実証計画（まだ結果はない）

### フェーズ1: 計測妥当性（同意を得た健常成人で実施）

- カメラ角度、遮蔽（テーブル、手、食器）、照明、衣服、体格、食事動作、姿勢維持の組み合わせを撮影。
- 姿勢の変更時刻を人手ラベルで付け、**検出感度、偽警告/分、検知遅延、`unknown` 時間比、通知/分**を集計。
- 同じ姿勢の繰り返し、基準再登録、別日撮影による変動を比較。個人別の許容差・持続時間を調整する。
- 既知角度の治具や複数カメラで角度誤差を評価する。MediaPipe world 座標の数値をそのまま実関節角とみなさない。

### フェーズ2: 使用性（食事介助・模擬食事）

- フィードバックあり／なしで、座位修正までの時間、座位の維持、主観的な負担、食事への集中、介助者の負担を比較。
- 誤通知による不必要な首・体幹の修正、過度な注意喚起、通知停止の使用頻度も記録。
- 調査対象に嚥下障害のある方を含める場合は倫理審査と専門職の監督を前提とし、食形態・姿勢・摂食可否をソフトで決めない。

### フェーズ3: 臨床的な有効性を検討する場合

- 姿勢の検出精度や主観的使用性は**誤嚥予防の証拠にならない**。VFSS / FEES 等の専門的嚥下評価の代用はできない [1]。
- 臨床アウトカムを主張する前に、適切な比較対照・評価項目・安全監視・専門職の関与を備えた独立した研究計画が必要。
